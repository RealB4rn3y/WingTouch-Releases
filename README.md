## Installation

1. Download the latest WingTouch installer using the button above.
2. Run `WingTouch-Setup-0.3.1-windows-x64.exe`.
3. Follow the Windows installation steps.
4. Start WingTouch.
5. Start Microsoft Flight Simulator 2024.
6. Open WingTouch from the system tray.
7. Use **Open Tablet QR** or **Copy Tablet URL** to connect your iPad or tablet.

WingTouch runs locally on your simulator PC.  
No separate tablet app, Python, Node.js or other development tools are required.

> WingTouch uses your local network to connect tablets and other devices to the simulator PC.
